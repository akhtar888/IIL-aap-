# IIL English Speaking Institute

Student / Teacher / Admin app — React + TypeScript + Tailwind + Supabase.

- Student: Dashboard, Attendance, Homework, Vocabulary (EN+HI), Grammar (EN+HI), AI Tutor, Courses, Mock Tests, Certificates
- Teacher: Attendance, Homework assign/grade, Progress
- Admin: Users, Courses, Mock Tests, Teacher Assignments, Analytics

Setup: `npm install` → `.env` (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY) → `npm run dev`
